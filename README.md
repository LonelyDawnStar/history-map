# History Map Editor

태블릿과 PC에서 사용할 수 있는 가상 역사/지정학 지도 편집기입니다.

## 현재 기능

- 실제 세계 해안선 기반 무국경 백지도
- 지도 이동 / 확대 / 축소
- 국가 생성 및 색상 지정
- 폴리곤 방식 영토 그리기
- 자유 국경선 그리기
- 역사적 사건 마커 추가
- 연도 변경 및 시점별 표시
- 실행 취소
- 프로젝트 JSON 저장 / 불러오기
- 태블릿 반응형 UI

## Vercel 배포

Vercel에서 이 GitHub 저장소를 Import하면 별도 빌드 명령 없이 정적 사이트로 배포할 수 있습니다.

Framework Preset은 `Other`, Build Command는 비워 두고, Output Directory도 비워 두면 됩니다.
